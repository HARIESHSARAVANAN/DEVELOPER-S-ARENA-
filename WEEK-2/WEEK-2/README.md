# 🎓 Student Grade Calculator

A beginner-friendly Python project developed as part of **Week 2 of The Developers Arena Internship Program**.

This project calculates a student's total marks, percentage, and grade based on marks entered for five subjects. It also validates the input and prevents invalid marks from being entered.

---

## 📌 Project Overview

The **Student Grade Calculator** is a console-based Python application that allows the user to:

- Enter the student's name
- Enter marks for five subjects
- Validate that marks are between 0 and 100
- Calculate the total marks
- Calculate the percentage
- Determine the student's grade
- Display an encouraging message based on the grade

The project demonstrates fundamental Python concepts such as:

- `if-elif-else`
- `for` loops
- `while` loops
- Functions
- Lists
- User input
- Exception handling
- Mathematical calculations

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Understand conditional statements in Python.
2. Practice using `for` and `while` loops.
3. Learn how to create and use functions.
4. Validate user input.
5. Handle invalid input using `try-except`.
6. Work with lists and calculations.
7. Build a complete Python console application.
