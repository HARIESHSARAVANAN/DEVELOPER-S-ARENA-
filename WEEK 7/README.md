
## Methods
Descriptive statistics, histogram/density analysis, Shapiro-Wilk normality tests, Pearson correlation, two Welch t-tests, one-way ANOVA, 95% confidence intervals, and multiple linear regression.

## Dataset limitation
The uploaded files are identical 500-row customer churn datasets. They do not contain marketing-spend or sales-revenue columns, so the marketing-vs-revenue analysis cannot be completed from these files.
