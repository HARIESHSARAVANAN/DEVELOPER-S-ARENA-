## 📌 Project Overview

**Sales Data Analysis** is a Python command-line program built with
**pandas** that reads a raw sales CSV, cleans it, and generates a
complete sales report directly in the terminal.

The script handles missing values, removes duplicates, calculates key
business metrics, and ranks products by performance — turning a messy
spreadsheet into an instant, readable report.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Load and inspect a real-world CSV dataset
- Practice data cleaning with pandas (type conversion, null handling)
- Remove duplicate records
- Calculate summary statistics (revenue, quantity, averages)
- Perform group-by aggregation for product-level insights
- Identify top-performing products
- Display clean, formatted console output
- Understand the end-to-end flow of a data analysis script
