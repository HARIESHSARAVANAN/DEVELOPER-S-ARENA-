# LINEAR REGRESSION FROM SCRATCH

Using **Area** as the single predictor:

- Slope: `7,771.6924`
- Intercept: `3,436,118.79`
- R² on full dataset: `0.6341`

Formula:

`Price = Intercept + Slope × Area`

This implementation demonstrates the underlying least-squares idea before using scikit-learn's `LinearRegression`.
