# Personal Introduction Program

## Project Overview

The Personal Introduction Program is a simple Python command-line
application that collects personal information from the user and
displays it in a clear and friendly format.

The program asks the user for their name, age, hobbies, city,
favorite programming language, field of study, and extra-curricular
activities.

## Objectives

- Practice Python variables
- Understand user input using `input()`
- Practice displaying output using `print()`
- Understand integer type conversion
- Practice strings
- Understand functions
- Practice basic Python program structure
- Use variables to store and display user information

## Technologies Used

- Python 3
